# Marla 0.1.0 Release Record

Status: Preparing — Alpha not yet accepted or publicly released

Release contract: `docs/versions/0.1.0/`

## Intended outcome

Marla 0.1.0 是项目所有者可日常试用的 Apple Silicon macOS Alpha，提供划词翻译、Vision 本地截图 OCR 翻译和快速输入，并通过用户配置的 OpenAI-compatible 流式 API 翻译文字。

## Implemented baseline

- 原生 SwiftUI/AppKit 菜单栏应用和附近结果卡片。
- 嵌入式 Rust 静态库、版本化 C ABI、HTTP/SSE、取消和错误映射。
- Accessibility 选区读取、ScreenCaptureKit 框选、Vision OCR、快速输入。
- Keychain 凭证、快捷键、权限引导、朗读、复制、重试、固定和对照。
- Debug/Release 构建与时间戳测试 App 验证脚本。

稳定实现基线：Git commit `88954bb`。

## Verified evidence

- Rust 16 项测试通过。
- Swift 18 项测试通过。
- Xcode Debug App 构建通过。
- `Marla_test_202608060135.app` 的 Bundle ID、版本、最低系统、arm64、可执行文件和签名检查通过。
- 真实 App 的浅色、深色、Reduce Motion 和主要状态已完成五维视觉复评，全部至少 7/10。

## Remaining before acceptance

- Terminal、Safari、TextEdit、VSCodium 的最新真实选区兼容验证。
- 单屏/多屏/混合缩放的真实截图裁剪对比和权限持久化验证。
- UI P95、Rust-to-Swift delta P95 和内存预算测量。
- 0.1.0 验收清单中的其余项目。

## Explicitly not included

云端结构化 OCR、上下文增强、历史、原位覆盖、文档工作区、DMG、公证、自动更新和公开分发。

本文件在正式接受 0.1.0 前只作为发布准备摘要；最终发布时必须根据真实产物和 `ACCEPTANCE.md` 更新。
