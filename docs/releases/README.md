# Release Records

这里保存实际发布准备与发布摘要，而不是日常开发日志。Marla 当前处于 `Incubation / Unreleased`，没有活动 Release Record。

- 只有项目所有者明确启动发布准备时才选择版本号，并在 `docs/versions/<version>/` 建立新合同。
- 同时创建的 `docs/releases/<version>.md` 以 `Preparing` 开始，汇总最终交付、验证证据和已知限制。
- 未满足发布合同或未获项目所有者发布授权的版本不能写成已发布。
- 撤回草案标记为 `Withdrawn before release`；它没有占用一个已发布版本，也不约束孵化期范围。
- 具体版本提升规则见 `docs/development/VERSIONING.md`。
- 日常进度只更新 `development/STATUS.md` 和当前 Task。
