# Release Contracts

This directory contains release-specific scope and acceptance contracts. It is not the home of current product specifications or daily development state.

- Marla is currently `Incubation / Unreleased`; no contract here is active.
- A new `<version>/` contract is created only after the project owner explicitly starts release preparation and chooses that version.
- Current behavior belongs in Product, Feature, Architecture, code, tests, Task, and `STATUS.md`.
- Withdrawn contracts remain historical evidence and do not freeze incubation scope.

`0.1.0/` is a withdrawn draft that was never accepted or published. See `docs/development/VERSIONING.md` for the active lifecycle.
